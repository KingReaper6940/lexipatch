Normalization and supported letters

Words and filler letters are normalized to NFC and uppercased with Unicode default casing. This can change spelling or expand letters, such as ß becoming SS. Review the normalized word list below.

Each cell contains one Unicode letter code point. Precomposed accented letters and Hangul syllables work; sequences that still contain combining marks, emoji, punctuation or digits are rejected. This is not full language or grapheme support.
